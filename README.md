# 刘燠 · 留一点好奇

个人网站与学习、创作目录。首页保留头像和七位探头角色，通过“课程作业 / 我的小玩意”两个标签切换内容，由本人和 Codex 联合搭建。

## 页面

- `index.html`：个人主页。头像、七位探头 AI 伙伴、两个分类标签和素材署名。
- `projects.js` 保存两份课程作业和两款安卓应用《记账》《拼豆图纸》。“我的小玩意”中的应用封面放在 `covers/` 目录，点击“下载安卓版”可进入对应应用的最新发布页。
- `homework-01.html`：第一次作业的完整可玩展示版，含四份 AI 使用记录、游戏体验、拼豆实验与“返回个人主页”。
- 第二次作业继续位于独立网站；主页链接到现有地址，新标签页打开，保留个人主页。
- `CREDITS.md`：角色来源与图片处理说明。
- `records/`：四份可独立阅读的 AI 使用 Markdown 记录；网页已经内嵌这些记录，不依赖外部 Markdown 文件。

## 发布到现有 liuyu-ai 仓库

已有分类标签时，将 `projects.js` 和 `covers/` 上传到仓库根目录即可更新作品列表。从旧版首页升级还需上传 `index.html`。

全新发布时，将本目录的 `index.html`、`projects.js`、`covers/`、`homework-01.html`、`CREDITS.md` 和 `README.md` 一起上传。`records/` 保存可单独阅读的记录。

GitHub 仓库：`mufu520/liuyu-ai`。保留原有 Pages 发布分支和目录，无需新建仓库。不要把外层“上传到liuyu-ai”文件夹也上传成子目录。不要只上传 ZIP。

发布后原个人网站地址继续使用：`https://mufu520.github.io/liuyu-ai/`。

第二次作业地址保持：`https://mufu520.github.io/ai_homework/`。如果尚未更新到“记忆试炼”版，请同时把单独提供的“更新ai_homework”文件夹内三个文件覆盖到该作业仓库根目录。

仓库里原来的四个“使用.md”可以保留；这里的 `records/` 只是整理方式。不要因为整理首页而删除不清楚用途的其他文件。

## 离线查看

首页内嵌样式、交互脚本和原有素材，但项目清单单独保存在 `projects.js`。将它与 `index.html` 放在同一文件夹，双击首页即可预览，不需要启动服务。第一次作业使用相对链接；第二次作业链接为已发布网站，访问需要联网。

伙伴点击后出现预设对白，并非实时 AI 聊天。右上角（手机右下角）的按钮可切换为安静阅读；选择仅保存在本机浏览器。支持键盘操作、减少动态效果偏好和窄屏布局。

七位角色为 DeepSeek、豆包、ChatGPT、Claude、Grok、Gemini、千问。已按参考形象用图片接口重绘成统一 Q 版画风；豆包保留指定表情图中的短发与红围巾。头像保持原图。详细来源及 AI 重绘说明见 `CREDITS.md`。

## 后续维护

新增项目时，编辑 `projects.js`，按文件顶部示例向数组添加一项。`category` 填 `course`（课程作业）或 `toys`（我的小玩意），`href` 填项目发布后的体验网址，不能用仓库代码页替代。填写真实标题、介绍；`image` 可填仓库内封面路径，例如 `covers/my-game.webp`，不填则显示文字封面。项目会自动出现在对应标签下，数量也会更新。只上传修改后的清单与新增封面即可。

更新某个项目本身：在该项目自己的仓库更新内容。只要项目网址不变，个人主页无需修改。新建项目仓库不会自动注册到目录，需要在清单中添加一次。

两个标签支持键盘左右方向键、Home、End 切换。`#course` 直接打开课程作业，`#toys` 直接打开我的小玩意。

开发版位于工作区 `personal-site/`，由 `tools/build.py` 生成发布文件；开发脚本、原始输入图片、下载缓存及本机路径不放入上传目录。

角色及素材权利归各自权利人。详见 `CREDITS.md`，不要把角色插画当作整个站点开源许可的一部分。
