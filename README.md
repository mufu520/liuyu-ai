## 代表实践

### 图片转拼豆图纸 Android 应用

从“把图片变成可以照着制作的拼豆图纸”这个需求出发，使用 AI 辅助实现图片导入、裁剪、色卡匹配、逐格编辑、用豆统计及 PNG / PDF 导出。

我根据试用情况反馈图片比例、图纸尺寸等问题，再由 AI 协助修改。历史记录中的 0.3.0 版本最高支持 **240 × 240 格**，有构建、测试、Lint 和正式签名 APK 的交付记录；未确认应用商店上架。

### Python 学习与代码练习

使用 AI 解释语法、分析报错，制作逐行注释示例、交互式练习与速查材料。练习内容包括列表、格式化输出、日期计算、下标和边界处理等。

在部分作业修改案例中，采用“AI 指出问题，我继续修改”的方式；历史记录中有三轮迭代自行修正五处代码错误的案例。学习时也曾主动关闭代码补全，希望保留自己组织代码和练习的过程。

### 网页游戏与内容创作

《雾港电台》将中文分支剧情、多结局、物品与状态系统、自动存档结合到网页中，历史记录验证过页面加载和主要界面。

此外，还尝试了历史案件主题演示文稿、角色头像提示词、桌宠素材和游戏录屏剪辑构思。这些任务的完成程度不同：有文件交付的案例，也有仅形成方案或视觉效果尚未满意的尝试。

### 论文阅读与工具连接

使用 DSH 辅助整理五篇视觉语言导航（VLN）相关论文，将方法、贡献、实验和局限进行对照，并生成通俗说明。自动抽取不清楚的文字和数字仍需回到原论文核对。

工具探索包括 FastCtx 用户级模式、MCP 连接和点单 skill。其中有成功注册并调用文件工具的记录，也有未完成的配置或流程尝试。

## 我如何与 AI 协作

1. **说明目标和约束。** 提供具体需求、已有材料，以及格式、运行环境或使用场景。
2. **获得第一版结果。** AI 参与代码、草稿、素材或方案的生成。
3. **检查并反馈问题。** 根据实际情况指出比例、交互、代码逻辑或表达上的问题；部分代码练习由我自行修改。
4. **继续迭代并记录状态。** 区分已经完成、经过验证、仍是原型和暂未解决的部分。

不同任务中，AI 的参与程度并不相同。有的侧重解释和纠错，有的直接参与实现或整篇改写；不能把所有生成内容视为我独立完成的成果。

## 使用 AI 后的体会

- **具体反馈比笼统评价更有用。** “图片被拉伸”“数字没有同步”“这一段逻辑接不上”，比一句“不好”更容易推动修改。
- **看懂结果和独立完成仍有距离。** 读懂示例之后，还需要练习拆解问题、组织步骤和检查边界。
- **生成不等于验证。** 页面能打开、素材格式通过或 AI 给出肯定回答，都不能代替实际检查。
- **未完成的尝试也值得记录。** 配置失败、效果不满意和功能尚未接入，可以帮助判断下一步该验证什么。
