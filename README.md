# 刘燠 · 留一点好奇

个人网站与课程作业目录。首页保留头像、七位探头角色和两次作业的直接入口，由本人和 Codex 联合搭建。

## 页面

- `index.html`：个人主页。头像、七位探头 AI 伙伴、两次作业入口和素材署名，不另设作品介绍区域。
- `homework-01.html`：第一次作业的完整可玩展示版，含四份 AI 使用记录、游戏体验、拼豆实验与“返回个人主页”。
- 第二次作业继续位于独立网站；主页链接到现有地址，新标签页打开，保留个人主页。
- `CREDITS.md`：角色来源与图片处理说明。
- `records/`：四份可独立阅读的 AI 使用 Markdown 记录；网页已经内嵌这些记录，不依赖外部 Markdown 文件。

## 发布到现有 liuyu-ai 仓库

在仓库根目录上传本文件夹中的文件，覆盖同名 `index.html` 和 `README.md`，新增 `homework-01.html` 与 `CREDITS.md`。`records/` 是可选的独立记录归档。

GitHub 仓库：`mufu520/liuyu-ai`。保留原有 Pages 发布分支和目录，无需新建仓库。不要把外层“上传到liuyu-ai”文件夹也上传成子目录。不要只上传 ZIP。

发布后原个人网站地址继续使用：`https://mufu520.github.io/liuyu-ai/`。

第二次作业地址保持：`https://mufu520.github.io/ai_homework/`。如果尚未更新到“记忆试炼”版，请同时把单独提供的“更新ai_homework”文件夹内三个文件覆盖到该作业仓库根目录。

仓库里原来的四个“使用.md”可以保留；这里的 `records/` 只是整理方式。不要因为整理首页而删除不清楚用途的其他文件。

## 离线查看

两个 HTML 各自内嵌样式、脚本与素材；双击 `index.html` 可看主页，第一次作业使用相对链接。第二次作业链接为已发布网站，访问需要联网。

伙伴点击后出现预设对白，并非实时 AI 聊天。右上角（手机右下角）的按钮可切换为安静阅读；选择仅保存在本机浏览器。支持键盘操作、减少动态效果偏好和窄屏布局。

七位角色为 DeepSeek、豆包、ChatGPT、Claude、Grok、Gemini、千问。已按参考形象用图片接口重绘成统一 Q 版画风；豆包保留指定表情图中的短发与红围巾。头像保持原图。详细来源及 AI 重绘说明见 `CREDITS.md`。

## 后续维护

主页与作品内容分开，之后可以添加其他课程、项目或文章，不必沿用某次作业的风格。现有项目保留各自的界面。

开发版位于工作区 `personal-site/`，由 `tools/build.py` 生成发布文件；开发脚本、原始输入图片、下载缓存及本机路径不放入上传目录。

角色及素材权利归各自权利人。详见 `CREDITS.md`，不要把角色插画当作整个站点开源许可的一部分。
